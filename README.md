# 📋 Enquiry Management System

## 📌 About the Project
The **Enquiry Management System** is a software application designed to manage and track enquiries efficiently. It helps users record new enquiries, store customer information, update enquiry status, and manage enquiry records in one place.

This project aims to reduce manual work and improve the efficiency of enquiry handling.

## 🎯 Objectives
- To maintain enquiry records digitally.
- To simplify enquiry registration and tracking.
- To manage customer information efficiently.
- To monitor enquiry status and updates.
- To reduce paperwork and manual errors.

## ✨ Features
- ➕ Add new enquiries.
- 👁️ View all enquiry records.
- ✏️ Update enquiry details.
- 🗑️ Delete enquiry records.
- 🔍 Search and track enquiries.
- 📊 Manage enquiry status.

## ⚙️ Installation and Setup

### 1. Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project Folder
```bash
cd Enquiry-Management-System
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Application
```bash
python app.py
```

### 5. Open in Browser
Open the local URL displayed in the terminal, usually:

`http://127.0.0.1:5000/`

## 🚀 How to Use
1. Start the application.
2. Open the website in your browser.
3. Enter the required enquiry details.
4. Save the enquiry record.
5. View, search, update, or delete records as supported by the application.
6. Track the enquiry status.
